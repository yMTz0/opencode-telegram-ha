# Workspace da VPS 🤖

Esta é a sua pasta de trabalho **na nuvem** (Render).

- Quando o PC está ligado, o bot responde de lá (arquivos do PC).
- Quando o PC desliga, a VPS assume e é **aqui** que o bot trabalha.
- Arquivos criados aqui **não** aparecem no PC (você escolheu modo separado).

## Como usar quando a VPS assumir
1. No Telegram: `/projects` → escolha `/app/workspace`
2. `/new` para começar uma sessão limpa aqui dentro
3. Peça tarefas normalmente; baixe arquivos com `/ls`

## Pastas
- `notas/` — anotações rápidas
- `ideias.txt` — rascunhos
